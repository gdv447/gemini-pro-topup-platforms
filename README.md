## 代充、成品号、CDK 激活链接不是一回事

**代充**指的是平台在你的账号上完成付款和开通，账号仍然归你，聊天记录、云盘文件、订阅关系都留在原来的 Google 账号里。代价是你得把账号的登录状态凭据（通常叫 Session 或 access token）交给平台。

**成品号**是卖家给你一个已经注册好的账号。价格能压到很低，但账号不在你名下，哪天被找回、被换号、被回收权益，你都没有太多办法。V2EX 上就有用户提到在卡站买的成品号「用不到半天小号都被封了」。

**CDK／激活链接**是一串兑换码或者一条开通链接。海外卡网上的 Gemini Pro 激活类商品能标到很低的价，搜索里能看到的公开报价从 4.99 美元到 18 美元不等，卖点是「18 个月」「5TB」「可家庭共享」。这类低价基本来自地区优惠、学生资格、家庭组名额或者批量采购，官方没有承诺过权益一定保留——买之前最好默认它可能中途被回收。

三种里面，代充贵一点，但账号归属清楚，这是它存在的理由。

## 常见问题

**代充会不会导致账号被封？**
风险不能归零。代充走的是平台侧的支付通道，不是用异常方式登录你的账号，所以封号概率比买成品号低。但账号本身的合规状态才是主要变量——注册地、常用 IP、是否有异常登录记录，这些平台管不了。

**必须用自己的 Google 账号吗？**
代充模式就是用你自己的账号，这也是它比成品号贵的核心原因。如果你只是想低成本试一下 Gemini Pro 到底适不适合自己，合租方案更省，代价是额度和对话隔离。

**多久能到账？**
公开教程给的参考量级是付款后几十分钟内。遇到上游支付通道波动会延长，这种情况平台通常会走退款。

**能退款吗？**
订阅失败一般可以退。已经成功开通并使用的周期，基本不会退。

**便宜到几美元的激活链接能买吗？**
能买，但要清楚你在买什么。这类低价通常绑定的是地区优惠、学生资格或家庭组名额，官方从未承诺长期保留权益，中途被回收是这类商品公认的风险之一。
